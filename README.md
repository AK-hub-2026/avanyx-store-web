# AVANYX Store Ecosystem

Official repository for AVANYX Store — Secure APK marketplace and modern application distribution ecosystem featuring native Android client, Web Store, Developer Console, Student Publishing, and Root Admin management.

---

## ✨ Features

- **Storefront & Catalog**: Rich marketplace with search, category filtering, ratings & reviews, and instant APK downloads.
- **Developer Console**: App release pipeline, package verification, version management, and real-time download & view telemetry.
- **Student Console**: Dedicated sandbox, student pack resources, learning tracks, and permissions matrix.
- **Admin Console**: Category management, editorial promotions, security oversight, and system analytics.
- **AVANYX Identity**: Seamless unified authentication supporting Google, GitHub, and email credentials with credential linking.
- **Native Android Client**: Built with Kotlin and Jetpack Compose (Material 3) supporting background APK downloading and local installations.

---

## 📂 Project Structure

- `src/` — React Web Storefront, Developer Console, Student Console, and Admin Console.
- `app/` — Native Android client built with Kotlin & Jetpack Compose.
- `backend/` — API controllers, middleware, and storage services.
- `docs/` — System architecture, roadmap, and security guidelines.
- `assets/` — Icons, screenshots, and visual branding assets.
- `supabase/` — Database schema and row-level security definitions.

---

## 🛠 Technology Stack

- **Web Frontend:** React, TypeScript, Tailwind CSS, Lucide Icons, Vite
- **Android App:** Kotlin, Jetpack Compose, Material 3, Room, WorkManager
- **Cloud Database & Auth:** Firebase Firestore & Firebase Authentication
- **Object Storage:** Supabase Storage
- **CI/CD:** GitHub Actions for automated build and APK verification
